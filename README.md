# Raifal A Buhari — Portfolio

Personal site for **Raifal A Buhari**, software engineer based in Dubai.

## Preview

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

Then visit the local URL it prints (usually `http://localhost:3000`).

## Contents

- Profile, experience, selected projects, and skills from the resume
- Contact links: email, phone, LinkedIn
- Live Dubai (GST) clock on the hero

## Deploy

Any static host works: GitHub Pages, Netlify, Vercel, or Cloudflare Pages. Point the host at this folder; there is no build step.
